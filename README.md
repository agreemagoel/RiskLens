# RiskLens
RiskLens is an AI-powered credit and fraud risk intelligence platform built to mirror how a real bank or fintech risk team would approach credit and fraud analytics — from raw transaction/customer data through machine learning models, explainability, and executive reporting, entirely on free, local infrastructure.

The platform tackles two distinct risk problems using real Kaggle datasets: fraud detection on 284,807 anonymized credit card transactions (0.17% fraud rate) and credit default prediction on 150,000 loan applicants (6.68% default rate). Rather than training a single model and stopping there, RiskLens compares Logistic Regression, Random Forest, and XGBoost for each problem, selecting the best performer based on the metric that actually matters for imbalanced classification — PR-AUC for fraud (0.881, XGBoost) and ROC-AUC for credit risk (0.866, Random Forest) — instead of naive accuracy.

Every prediction is explainable: SHAP values identify exactly which features drove each risk score, and a custom Risk Analyst Copilot translates that into plain-English explanations without relying on any paid LLM API — eliminating hallucination risk while keeping the project 100% free to run. A separate Isolation Forest model flags behavioral anomalies (unusual amounts, off-peak transaction times), and all four signals — fraud probability, anomaly score, customer risk, and transaction risk — combine into a single weighted composite Risk Score.

The full pipeline is production-shaped: a FastAPI backend serves predictions and SHAP explanations via REST endpoints, a Streamlit dashboard supports operational investigation (transaction/customer lookup, model monitoring), a SQLite database backs fast lookups across both datasets, MLflow tracks every training run, and Evidently monitors data drift over time. A Power BI executive dashboard sits alongside Streamlit for higher-level portfolio reporting. The entire system is containerized with Docker and fully tested with an 18-test pytest suite covering both models and the risk engine.

Tech stack: Python, Pandas, Scikit-learn, XGBoost, SHAP, FastAPI, Streamlit, SQLite, MLflow, Evidently, Power BI, Docker.
